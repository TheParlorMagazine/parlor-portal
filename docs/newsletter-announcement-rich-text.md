# Newsletter Announcement editor

Only the newsletter Announcement block changes. The campaign editor, issue promotion, article/event/shop blocks, and support copy are unchanged.

The toolbar uses B, I, underlined U, a link icon, and an image icon. The image icon opens the existing upload/URL/media-library chooser inside the editor; the chosen image is inserted at the current cursor without replacing selected text. Existing images appear in the canvas. Selecting an image exposes full-width, left-wrap, right-wrap and removal controls. Its position between paragraphs is saved directly, and it can be dragged within the editor. Removing it clears the separate image field so it cannot return on reload. No unrelated editor or newsletter block changes.

Inline email styles and the image align attribute provide fallbacks; actual wrapping depends on the recipient's email client, particularly Outlook. No emails were sent during automated tests.

No migration is required. The existing issues.newsletter_announcement text column stores a versioned JSON envelope with kind newsletter_announcement. Version 1 retains html/layout/after compatibility; version 2 stores the image node position and alignment in the canvas HTML. The image source remains in the existing newsletter_announcement_img field. Existing plain text continues through the original renderer until edited. Opening the editor upgrades its draft while preserving text; only Save announcement persists it. The same encoded value travels through the existing preview, test, review, send and retry paths. HTML is rendered server-side through a parser-backed allowlist: paragraphs, breaks, strong/emphasis/underline, safe links and at most one marked announcement-image node. The node always uses the separate announcement image source, never a pasted or forged HTML source. Other images, event handlers and executable content are discarded.

Tests cover markup sanitization, unsafe links, plain-text compatibility, empty content, all layouts, unrelated newsletter content, editor formatting and links, image insertion without text loss, alignment reload and removal, desktop/mobile iframe previews and existing newsletter layout/test-email behavior.
