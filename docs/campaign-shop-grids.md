Campaign content sections support text, images, a nested shop grid, and a closing CTA. Use Add Section, then Add shop grid within that section. The intro and section body toolbars include Add button, which inserts a styled link at the cursor without creating a section. Search the public active product catalogue, select up to 12 products, reorder or remove selections, choose USD/EUR/GBP, and edit the shared product-button label. The section title, body and optional closing CTA use the existing controls. Buttons use customizable text and normalized URLs.

Product names, images, links and currency prices are captured when selected and stored with the existing campaign block metadata and generated body HTML. Remove and re-add a product to refresh its snapshot. Preview and test email use the same renderer as saved campaign HTML; no campaign migration is needed. Sending retains the existing consent, audience, scheduling and review checks. Selecting products never initiates checkout or sends email.

Shop grids default to two columns on desktop and stack on mobile. Each grid has a Layout selector to optionally stack products on desktop as well. Product images retain their natural proportions. Cloudinary email derivatives flatten transparency onto white before the final encoding; premature format transformations are removed so transparent pixels do not become black. Product text is escaped, links are normalized through campaignLinkUrl, and normal item-sale and bundle-only promotion displays retain their respective prices. Older blocks without a type continue to render as image/text sections. Previously saved standalone grid blocks reopen as content sections with a nested grid, preserving their headings, products, prices and CTA. Previously saved button sections remain editable.

Email product images use a public catalogue-ID/index endpoint at /shop/email-image/:id/:index. It fetches only supported catalogue storage hosts (configured Supabase public storage, Cloudinary, Wix media and Printify), rejects redirects, bounds response bytes/pixels, and emits a white-composited JPEG with no alpha. It never proxies a caller-supplied URL. This covers Supabase WebP images as well as Cloudinary artwork; an opaque black background already present in the source requires replacing that source. Save the draft to regenerate older product image links. Test emails have unique timestamped subjects to reduce Gmail conversation grouping and repeated-content collapsing; the inbox still controls trimming.
