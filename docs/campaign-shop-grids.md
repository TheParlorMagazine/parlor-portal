Campaign content sections support image/text (the existing default), shop grids, and standalone buttons. Use Add shop grid or change a section's type to Shop grid. Search the public active product catalogue, select up to 12 products, reorder or remove selections, choose USD/EUR/GBP, and edit the shared product-button label. The section title, body and optional closing CTA use the existing controls. Add button creates a section with a customizable CTA label and URL.

Product names, images, links and currency prices are captured when selected and stored with the existing campaign block metadata and generated body HTML. Remove and re-add a product to refresh its snapshot. Preview and test email use the same renderer as saved campaign HTML; no campaign migration is needed. Sending retains the existing consent, audience, scheduling and review checks. Selecting products never initiates checkout or sends email.

Shop grids use a two-column presentation table with inline styles and mobile stacking in the email template. Product text is escaped, links are normalized through campaignLinkUrl, and normal item-sale and bundle-only promotion displays retain their respective prices. Older blocks without a type continue to render as image/text sections.
